# DOT — Habit Tracker for Obsidian

DOT is a lightweight, open-source habit tracker plugin for Obsidian that brings daily check-in functionality directly into your vault.

## Features

- **Project Squares** — Colorful tiles on a main dashboard for today's items
- **Quick Recording** — Confirmation, counting, text, date adjustment, and attachments
- **Data Views** — Weekly, monthly, and ranking views for review
- **Markdown Write-back** — All records saved as plain Markdown into project notes
- **Project Templates** — Choose recording method (check, count, target, heatmap, trend)
- **Custom Layout** — Adjustable grid columns and tile sizes
- **Charts** — Heatmaps and SVG line charts for visual insights
- **Archiving** — Move items out of daily view while preserving history

## Installation

### BRAT (recommended)
1. Install the BRAT community plugin
2. Add `https://github.com/[your-org]/dot` to BRAT
3. Enable DOT in Community Plugins

### Manual
1. Download `main.js`, `manifest.json`, `styles.css` from latest release
2. Place in `.obsidian/plugins/dot/`
3. Enable DOT in Community Plugins
